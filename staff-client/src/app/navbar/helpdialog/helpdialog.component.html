Employee Search Guides

  • For names containing an apostrophe, the apostrophe must be included to receive expected results.
  • For hyphenated names, you can search on either part of the name.
  • The Filter text field is used for filtering the current result set. One keyword may be used to search through your current data list.
    • For example, simply type in the “filter” text box a specific department, location, or job title, and it will filter the result set according to that (in real time).
    • The only drawback (or limitation) of Filter is that it can only do one keyword at a time and not multiple. For correct search results with multiple criteria, please reset and make new search with proper inputs.
  • For dropwdown categories like Division, Department, Location, and Job Group, an empty value selection is the equivalent of any and/or all for that category. So if a location or division is not specified, then the result will return all divisions or locations.
  • To sort, click on any bold header to sort the search result according to that category (Name, Title, Direct Dial, Phone, Location, Division, Department, Job Group)
    • One click sorts in ascending order, the second click in descending, and the third click on the header clears the sorting.
    • There is an arrow to the right indicating the sort order when the header is clicked.
  • To restart or make a new search, simply click Reset and start over.

Types of Searches

You can conduct the following types of searches:

  • Partial Value (First Name, Last Name or Job Description)
    • EXAMPLE: Enter “Mar” in First Name field returns all records where First Name contains “Mar” substring.
  • Combination Partial Values
    • EXAMPLE: First Name -- “Mar” and Job Description- “Program” returns all records where First Name contains substring Mar and Job Description contains Program.
  • Drop-Down List
    • EXAMPLE: Select Operations from Division to return all employee records for staff in Operations.
